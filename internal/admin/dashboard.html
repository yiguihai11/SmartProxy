TLS Certificate
Built-in root CA & CA-signed leafDetecting...

The panel serves HTTPS with a short-lived leaf certificate signed by a built-in root CA (admin.crt). Install that CA as a trusted certificate authority on each device that opens the panel — the leaf is then trusted automatically and the "untrusted" warning disappears. The CA is a stable trust anchor: it does not change across app reinstalls or when the panel's addresses change, so a device only needs it installed once. Android 7.0+ requires a lock-screen PIN to install a CA; iOS needs the profile installed then trusted in Settings > General > VPN & Device Management.

The leaf covers localhost, 127.0.0.1, ::1 and every name/IP in admin_cert_sans (config listen block). If a LAN address is missing, add it there and restart — only the leaf is re-signed; the CA stays the same, so devices that already trust it keep working. A user-supplied admin_ca.{crt,key} next to the config overrides the embedded one; binaries built without any CA fall back to a single self-signed certificate.
